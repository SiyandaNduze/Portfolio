# Siyanda Nduze — Developer Portfolio

A single-page portfolio website introducing Siyanda Nduze, highlighting selected software projects, technical skills, experience, education, and contact links.

## Highlights

- Dark visual theme with teal and blue accents.
- Responsive layout for desktop and mobile screens.
- Animated role text and scroll-reveal effects.
- Sections for about, skills, projects, experience, and contact.
- Project cards link to their GitHub repositories.

## Run locally

Clone the repository:
```bash
git clone https://github.com/SiyandaNduze/Portfolio.git
cd Portfolio
```

Open `index.html` in a browser, or serve the folder locally:
```bash
python -m http.server 8000
``
Visit http://localhost:8000.

No build step or package installation is required. The page loads web fonts from Google Fonts, so an internet connection is needed for those fonts.

## Project structure

- `index.html` — page markup, styles, project content, and interaction scripts.

## Customisation

Edit the project cards, skills, biography, experience, and contact links in `index.html`. Keep project descriptions and counts aligned with the current portfolio.
